# Office sessions

Each session is about twenty minutes. Use a test login. Do not change a live hotel rate or the saved season during practice.

## Owner

1. Sign in at `/office/login`. Home lists creating logins, rates, public page text, request status, and delete.
2. Open **Users**. Create one Editor and one Manager with **Create login**.
3. Open **Tours** and **Rates** so both links are visible.
4. Open **Requests**. If a test request is there, set the status to **In progress** and click **Save status**. **Delete** is on this screen. Leave a real guest request in place.
5. Click **Sign out**.

## Manager

1. Sign in as the Manager. Home says you can change rates and a request status, and you cannot edit public page text. **Tours** and **Users** are absent. **Delete** is absent on **Requests**.
2. Open **Rates**. Find **Quote**.
3. Set **Night number** to `2`, **Night rate** to a practice amount, and **Night hotel** to a practice name.
4. Set **Day** to `3` and **That day** to **No vehicle**.
5. Click **Save quote**. No red line means that quote is saved. The hotel rate rows and **Save season** were not part of this save.
6. Open **Requests** and change one test status with **Save status**.
7. Click **Sign out**.

## Editor

1. Sign in as the Editor. Home says you can edit public page text and read requests. **Rates** and **Users** are absent. A request has no status control and no **Delete**.
2. Open **Tours**, then open one tour. The screen title is **Edit tour**. Find the title. Click **Save tour** only when that change should show on the public tour page.
3. Open **Requests** and read one row. The message is text.
4. Click **Sign out**.
