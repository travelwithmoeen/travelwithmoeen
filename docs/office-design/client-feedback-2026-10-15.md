# Prototype defaults pending Moeen sign-off

These defaults are in the Meadow prototype so Moeen can sign off. They are not live office rules yet.

- With hotel is the default. The package includes a hotel and other services.
- No hotel keeps the other services. It has no hotel line, no nights, no rooms, no meals, no stickers, and no road breakfast.
- Hotel only asks for the city and the number of nights. It has no vehicle, day edit, toll, jeep, guide, extra, breakfast, or Lahore extra. On air it has no tickets, welcome pack, or entry, and it does not add the sticker or the infant extra.
- Under With hotel, Same hotel all nights is the default. One catalog pick covers every night. Change per night is one click.
- A package with neither a hotel nor other services is refused. Hotel only with no nights is that package.
- Guests on the website get the same three choices and see only the final total.
- The profit margin is a whole percent from 0 to 100 and starts at 20 percent.
- Until the catalog pick is changed, the untouched Skardu quote uses the published Deluxe twin rate, so the test total stays 140,400.
- Grade is a label on the hotel. The catalog chain is city, then hotel, then room, then occupancy.
- Hotel only counts rooms from the party already on the quote. Two adults use one room.
- The dashboard note says the mismatch with the costing file is being checked.
